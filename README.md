## Overview

OpenSplit is a community-built speedrun timer focused on Linux and macOS support, full LiveSplit split-file compatibility, and extensible plugin hooks for auto-splitters and external data sources.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OpenSplit** delivers the features you need in a clean, intuitive package.

</div>

## Key Features

| Feature | Description |
|---------|-------------|
| **Cross-Platform** | Native builds for Windows, macOS, and Linux without Wine |
| **LSS Compatibility** | Reads and writes LiveSplit .lss files without conversion |
| **Plugin API** | Rust and Python plugin interface for custom split logic |
| **HiDPI Support** | Crisp rendering on 4K and Retina displays with fractional scaling |
